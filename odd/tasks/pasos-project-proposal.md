# PASOS project proposal

## Objective

Define the academic scope and implementation proposal for PASOS, a first-entry legal orientation service, aligned with the Interfaces y Programación Web final-practical requirements.

## Problem and rationale

The project needs a clear, reviewable plan before implementation. The proposal must translate the strategic PASOS document into a feasible course project without promising a complete production platform.

## Acceptance criteria

- The README explains what PASOS is, what the repository will contain, and how the academic requirements will be demonstrated.
- The proposal preserves the strategic concept: human first legal orientation, not automated legal advice or guaranteed representation.
- The proposal covers the supplied Front and Backend requirements without introducing unrequested frameworks or production architecture.
- The proposal identifies the minimum entities, REST endpoints, views, components, forms, authentication, and verification evidence needed for the final project.
- The documentation distinguishes confirmed requirements from decisions still needing confirmation.
